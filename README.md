# Vinyl Vault for Alexa

An Alexa skill that answers questions about my record collection: what it is worth, which record is the most valuable, what has gone up, whether I own something, and what to play next. It is the voice front end for [Vinyl Value Vault](https://github.com/JakubMini/vinyl-value-vault).

> **Status:** just started. The plan and the first code are on their way in pull requests.
